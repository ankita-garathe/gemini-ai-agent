# Gemini AI Agent 🤖

A terminal-based AI Agent built using JavaScript and Google's Gemini API. This project demonstrates AI Function Calling, where Gemini understands user queries and automatically executes JavaScript functions.

## Features

- Addition of two numbers using the Sum function.
- Prime number checking.
- Real-time cryptocurrency price fetching.
- Gemini AI integration.
- Function Calling to execute custom JavaScript functions.
- Continuous conversation through terminal input.
- Conversation history management.
- Handles asynchronous operations using async/await.

## Technologies Used

- JavaScript (ES6+)
- Node.js
- Google Gemini API
- @google/genai
- readline-sync
- CoinGecko API
- Fetch API

## Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project:

```bash
cd gemini-ai-agent
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key
```

5. Run the project:

```bash
node src/Lmm.js
```

## Example Questions

- What is the sum of 10 and 20?
- Check whether 17 is a prime number.
- What is the current price of Bitcoin?
- Type `exit` to stop the agent.
